ABOUT THIS PROJECT

From student data
to useful signals.

This project demonstrates supervised machine learning for academic performance classification. The target category is derived from the dataset's Exam_Score.

PythonPandasScikit-learnFlaskDecision TreeRandom Forest

Class definitions used: Low = exam score below 65; Medium = 65 to 70 inclusive; High = above 70. These are project-defined thresholds, not official academic standards.
